get started

Three commands to a running assistant

01

Serve your GGUF models with llama.cpp

llama-server -m main-model.gguf  --port 8081
llama-server -m agent-model.gguf --port 8082
02

Install the backend and frontend

git clone https://github.com/nadeemmhdm/ai-brain-assistant
cd ai-brain-assistant/backend && pip install -r requirements.txt
cd ../frontend && npm install
03

Run everything with one command

python scripts/run_dev.py
